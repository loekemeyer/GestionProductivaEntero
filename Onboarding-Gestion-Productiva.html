1. Requisitos previos

Antes de empezar, asegurate de tener instalado en la PC:

  • Visual Studio Code (también llamado "VS Code"). Es un editor gratuito de Microsoft. Si no lo tenés, descargalo de https://code.visualstudio.com e instalalo siguiendo el asistente (todo siguiente, siguiente, finalizar).
  • Navegador web (Chrome, Edge, Firefox). Cualquier moderno sirve.
  • Cuenta de Google autorizada por administración. Si nunca te dieron acceso, pedile a tu encargado que te agregue. Si intentás ingresar con una cuenta no autorizada, el sistema te lo va a decir.
  • Acceso a la carpeta compartida del proyecto (normalmente en la unidad de red, por ejemplo Z:\AA IT\Gestion Productiva). Si no la ves, pedí permiso al área de sistemas.

2. Abrir Visual Studio Code

  1. Hacé doble click en el ícono azul de Visual Studio Code en el escritorio, o buscalo en el menú Inicio escribiendo "code".
  2. Esperá unos segundos a que cargue.

3. Abrir la carpeta del proyecto

  1. En Visual Studio Code, hacé click en el menú "Archivo" (arriba a la izquierda) o usá el atajo Ctrl + K seguido de Ctrl + O.
  2. Click en "Abrir carpeta..." (o "Open Folder..." si está en inglés).
  3. Navegá hasta la carpeta compartida del proyecto. Por ejemplo:
    • Z:\AA IT\Gestion Productiva (4)\Gestion Productiva (3)\Gestion Productiva (3)\Gestion Productiva\Gestion Productiva
  4. Click en "Seleccionar carpeta".
  5. Si te aparece una pregunta tipo "¿Confías en los autores de los archivos de esta carpeta?", hacé click en "Sí, confío en los autores".
[INSERTAR SCREENSHOT: Diálogo "Abrir carpeta" mostrando la ruta del proyecto seleccionada, y VS Code después con el árbol de archivos visible en el panel izquierdo (Explorador).]
Resultado esperado: En el panel izquierdo (Explorador) vas a ver muchas carpetas como Produccion, Talleristas, Prov Serv, Informes, etc. + archivos como login.html, index.html, envios-only.html.

4. Instalar la extensión Live Server (solo la primera vez)

Live Server es una extensión gratuita que levanta un mini-servidor web local para que el sistema funcione correctamente desde tu PC.

  1. En la barra lateral izquierda de VS Code, hacé click en el ícono de Extensiones (cuadraditos apilados, 4° desde arriba) o usá Ctrl + Shift + X.
  2. En el buscador, escribí "Live Server".
  3. El primer resultado es de "Ritwick Dey". Hacé click en "Instalar".
  4. Esperá unos segundos a que termine la instalación. Ya está listo, no hace falta reiniciar.
[INSERTAR SCREENSHOT: Panel de Extensiones con "Live Server" buscado, mostrando la extensión de Ritwick Dey y el botón "Instalar" o "Desinstalar" (si ya está instalado).]
¿Cómo sé si ya está instalado? En la barra de estado abajo a la derecha de VS Code debería aparecer un botón "Go Live" con un ícono de antena. Si lo ves, ya está instalado, podés saltar al paso 5.

5. Iniciar el servidor con "Go Live"

  1. Mirá abajo a la derecha de VS Code, en la barra de estado azul.
  2. Hacé click en "Go Live" (con un ícono de antena/wifi).
  3. Tu navegador por defecto se va a abrir automáticamente con una URL similar a http://127.0.0.1:5500 o http://127.0.0.1:5501.
[INSERTAR SCREENSHOT: Barra de estado de VS Code con el botón "Go Live" resaltado, y el navegador abriéndose con la URL local.]
Importante: mientras estés usando el sistema, NO cierres Visual Studio Code. Si lo cerrás, el servidor se apaga y el sistema deja de funcionar. Podés minimizarlo, eso sí.

6. Abrir Gestión Productiva en el navegador

Cuando Live Server abre el navegador, te lleva a la lista de archivos. Tenés que ir a la página correcta:

  1. Si te abrió un listado de carpetas → hacé click en login.html o en index.html (ambos te llevan al mismo lugar: el login).
  2. Si te abrió directamente la página de login (pantalla oscura con el logo "Gestión Productiva"), perfecto, seguí al paso 7.

7. Iniciar sesión con Google

  1. Hacé click en el botón "Continuar con Google".
  2. Se abre una nueva ventana de Google.
  3. Seleccioná o ingresá la cuenta de Google que te asignaron (la de la empresa).
  4. Si te pide contraseña, ingresala.
  5. Si Google te pregunta permisos de la aplicación, hacé click en "Permitir" o "Continuar".
  6. Vas a volver automáticamente al sistema.
[INSERTAR SCREENSHOT: Ventana de selección de cuenta de Google, mostrando una o más cuentas para elegir.]
Si te aparece un mensaje rojo: "Tu cuenta no está autorizada para usar esta aplicación", significa que el administrador no te dio acceso todavía. Comunicate con loekemeyer.n8n@gmail.com para solicitar acceso, indicando tu mail de Google de la empresa.

8. Pantalla principal del sistema

Una vez ingresado, vas a ver la pantalla principal con los módulos disponibles según tu rol:

  • Rol Logística: ves 4-6 botones grandes (Envíos PS, Envíos Tall, Entrega PS, Entrega Tall Cerv, Recepción Insumos, Calculadora).
  • Rol Admin: ves un menú completo con todos los módulos (Producción, Stock, Talleristas, Informes, etc.).

9. Solución de problemas (Troubleshooting)

9.1 — No veo el botón "Go Live"

Causa: la extensión Live Server no está instalada o VS Code no reconoció que se instaló.

Solución: volvé al paso 4 e instalala. Si dice "Desinstalar" pero el botón no aparece, cerrá VS Code y volvé a abrirlo.

9.2 — Live Server abre pero el navegador muestra "Esta página no funciona" o error 404

Causa: abrió en una URL que no existe (por ejemplo si tenía otro archivo abierto).

Solución: en la barra de direcciones del navegador, escribí manualmente: http://127.0.0.1:5500/login.html (probá también con 5501 si 5500 no anda).

9.3 — Al hacer click en "Continuar con Google", se abre y se cierra muy rápido

Causa: bloqueador de popups del navegador.

Solución: permití los popups para esta página. En Chrome, click en el ícono de candado a la izquierda de la URL → "Configuración del sitio" → Pop-ups: Permitir.

9.4 — Después de loguearme me lleva a una pantalla vacía o me bota de vuelta al login

Causa: sesión expirada o caché viejo.

Solución: cerrá todas las pestañas del sistema, presioná Ctrl + Shift + Supr en el navegador y borrá cookies + caché. Volvé a abrir y loguear.

9.5 — El sistema dice "Sesión expirada. Redirigiendo a login"

Causa: pasaron más de 24 horas desde el último login y Google requiere re-autenticación.

Solución: solo hacé click en "Continuar con Google" otra vez. Es automático, no perdiste nada.

9.6 — Funciona pero todo está muy lento

Causa: muchas páginas abiertas o muchos refrescos simultáneos.

Solución: cerrá las pestañas que no uses. Si el problema persiste, comunicate con sistemas — puede ser un tema del servidor de base de datos.

9.7 — Cerré Visual Studio Code sin querer y el sistema dejó de andar

Causa: al cerrar VS Code, Live Server se apagó.

Solución: volvé a abrir VS Code (paso 2) — debería abrir la carpeta del proyecto donde la dejaste. Hacé click en "Go Live" otra vez (paso 5).

9.8 — Veo errores rojos en una pantalla del sistema

Solución: tomá una captura del error y mandala a sistemas indicando: en qué pantalla estabas, qué hiciste justo antes, y qué dice el error.
